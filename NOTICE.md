This flake commits no upstream bytes and fetches upstream, the wheels and the npm packages only when a derivation is built, so evaluating or promoting this repository conveys nothing. Serving a built output — a store path from a cache, or an image built from one — conveys AGPL-3.0-only code beside this flake's patch, and for a service reachable over a network AGPL §13 then runs the corresponding-source offer to the recipient, covering upstream at the pinned revision together with the patch, the regenerated declarations and the Nix held here.
